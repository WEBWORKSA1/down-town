# Down.Town

Independent guides to the world's downtowns — **Explore**, **Live**, **Do Business** — with tools, lead generation, sponsorships, donations, contests and careers. Static Jekyll site for GitHub Pages (free plan).

- Live (GitHub Pages): https://webworksa1.github.io/down-town/
- Production domain: https://down.town (after DNS — see below)
- Build prompt: [BUILD-PROMPT.md](BUILD-PROMPT.md) · Research: [RESEARCH.md](RESEARCH.md)

## Configuration — one file

Edit `assets/js/config.js`:

- `payments` — paste a PayPal donate link, Stripe Payment Link, Buy Me a Coffee or Ko-fi URL to show instant-checkout buttons on the Support page. Blank = pledge form only.
- `adSlots` — paste AdSense display-unit slot IDs to add manual units at section breaks. Blank = Auto ads only.
- `relayAlias` — optional FormSubmit alias string; replaces the encoded address.
- The contact address is stored only as encoded fragments and assembled at runtime. Never paste a plain address anywhere in the site.

Prices (listings, sponsorships, contest prizes, donation tiers) live in the page files `list-your-business.html`, `advertise.html`, `contests.html` and `support.html`.

## Forms

All forms post to FormSubmit's AJAX endpoint. **The first submission triggers a one-time activation email** to the site inbox — click the link in it once and every form starts delivering. Each email subject reads `Down.Town | <form> | <name> | <city>`.

## Custom domain (down.town)

1. At the registrar, replace parking/forwarding with:
   - `A` @ → `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
   - `AAAA` @ → `2606:50c0:8000::153`, `2606:50c0:8001::153`, `2606:50c0:8002::153`, `2606:50c0:8003::153`
   - `CNAME` www → `webworksa1.github.io`
2. Repo → Settings → Pages → Custom domain: `down.town` → Save → tick **Enforce HTTPS** once the certificate is issued.
3. Commit a `CNAME` file containing `down.town` to `gh-pages` (Settings does this automatically).

## Build

Pages are generated by a Python script (not included in the site) and rendered by GitHub Pages' built-in Jekyll using `_layouts/default.html`. Every page body is wrapped in `{% raw %}` so content never collides with Liquid. To edit by hand, change the HTML between the raw tags.
