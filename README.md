# Down.Town

Independent guides to the world's downtowns — **Explore**, **Live**, **Find Space**, **Do Business** — with ten calculators, a seven-intent lead-generation funnel, a partner network, sponsorships, featured listings, reader support, contests and careers. Jekyll site built and hosted free by GitHub Pages.

- Live: **https://down.town** (GitHub Pages, custom domain via `CNAME`)
- Build prompt: [BUILD-PROMPT.md](BUILD-PROMPT.md) · Competitive research (47 sites): [RESEARCH.md](RESEARCH.md) · Content rules: [_build/CONTENT-SPEC.md](_build/CONTENT-SPEC.md)

## How it's built

```
_config.yml            site settings (url, AdSense client, owner contact)
_data/cities.json      one record per downtown: scores, tagline, events, video (generated — see below)
_data/tools.json       tool registry used by cards, hubs and the sitemap
_data/sections.json    the four lines + tools/events/videos
_layouts/              default, city, space, article
_includes/             header, footer, overlays, crumbs, faq, schema, cta, rail-lead, intent-grid, …
explore/ space/ live/ business/ tools/   content pages (front matter + HTML body)
assets/js/             main.js (core), v2.js (saved, exit-intent, sticky CTA, attribution, events),
                       funnel.js (Get matched), calc.js (new tools), tools.js (v1 tools), config.js
assets/js/search-index.js, cities-data.js, sitemap.xml, feed.xml   generated by Liquid at build time
_build/                local tooling — not published
```

### Add a city
1. Add a record to `_build/new-cities.json` (slug, name, region, rslug, country, district, lat, lng, scores, pair, tall).
2. Write `explore/<slug>.html` and `space/<slug>.html` following `_build/CONTENT-SPEC.md`, plus `_build/sidecars/<slug>.json` (tagline, verified video).
3. `node _build/merge-cities.js` → `node _build/lint.js explore/<slug>.html space/<slug>.html` → `node _build/render.js` → `node _build/check.js`.
Hubs, footer, sitemap, search, events calendar, videos, rankings and the funnel's city list update automatically.

Local preview needs Node only: `cd _build && npm i js-yaml gray-matter liquidjs` once, then the commands above. Output goes to `../_site-preview`.

## Configuration — `assets/js/config.js`

- `payments` — paste a PayPal donate link, Stripe Payment Link, Buy Me a Coffee or Ko-fi URL to show instant-checkout buttons on the Support page. Blank = pledge form only.
- `adSlots` — AdSense display-unit slot IDs for `incontent` and `sidebar` zones. Blank = Auto ads only.
- `relayAlias` — the FormSubmit alias string (see Forms). Once set, the encoded address is no longer used.
- The site inbox is stored only as encoded fragments and assembled at runtime. **Never paste a plain address anywhere in the site.**

## Forms

Every form posts to FormSubmit's AJAX endpoint. **The first submission triggers a one-time activation email** to the site inbox: click it once and all forms start delivering. FormSubmit then offers a random alias string; paste it into `relayAlias`.

Subjects are built for triage: `Down.Town | Lead A | Office space | Toronto | Name`. Lead emails include need, city, sizing, timeline, estimate, lead score and tier (A ≥ 65, B ≥ 40, C), consent record and first-touch source (UTM, referrer, landing page, device). A follow-up email carries the optional call preference and time windows.
